En resumen

gitbombando es una línea automática de producción de videos cortos. Todos los días a las 16 h revisa la página de proyectos destacados de GitHub, elige los 10 que más estrellas ganaron y arma un reel vertical que explica cada uno en portugués sencillo, con tarjeta, contador y gráfico. Sirve para quienes quieren saber qué está en auge en tecnología e IA sin leer inglés ni código. El video se publica automáticamente en YouTube (INEMA Tec), en el bot de Nei y en un tema fijo del grupo INEMA.TOOLS de Telegram. Para ejecutarlo, se necesita la máquina de INEMA con Python, Node, Codex, Claude Code y una suscripción a HeyGen.

Qué es

Un noticiero diario de GitHub, hecho por una máquina

Combina el motor de noticieros de r7ex (que surgió de eventosextremospub) con una recopilación propia de GitHub Trending.

🔥 Un gancho que detiene el dedo

La apertura presenta el dato más impactante del día (el número del #1, una gran empresa tecnológica o un proyecto polémico) en un titular diseñado en la portada. Está prohibido empezar con una lista («los 10 proyectos…»).

📊 Un gráfico para cada proyecto

Tarjeta con posición, foto de la persona responsable, explicación sencilla en portugués y estrellas; debajo, el contador llega al número cuando se menciona, y el gráfico muestra la curva de estrellas o el «antes × ahora».

⚙️ Sin presionar ningún botón

Temporizador a las 16 h, guion y revisión con Claude, avatar en el estudio de HeyGen, publicación en lives4, aviso en el bot v3 y publicación en el mismo tema de Telegram.

Cómo funciona

De Trending a Telegram, automáticamente

Cada etapa guarda un archivo en la carpeta de la edición (edicoes/AAAA-MM-DD-top10-dia/); si algo falla, Nei recibe un aviso de «Falló» en el bot con el motivo.

Registro de estrellas (cada hora)→ Recopilación de Trending (16 h)→ Guion (claude -p)→ Control→ Avatar + tarjetas + portada→ Edición→ Revisión→ lives4 · v3 · INEMA.TOOLS

📅 Día, semana y mes

El temporizador ejecuta auto/rodar.sh a las 16 h: siempre el Top 10 del día; los domingos, también el de la semana; el día 1, también el del mes.

⭐ Orden por estrellas

El Top 10 se ordena según las estrellas ganadas durante el período entre los proyectos que aparecen en Trending (el orden de la página combina otras señales).

🧾 Revisión antes de publicar

Un claude -p lee 18 cuadros del video. Si encuentra un defecto visible (título incorrecto, cuadro vacío, número cambiado), detiene todo; las sugerencias también llegan a Nei.

Requisitos previos

Qué debe estar instalado en la máquina

Es la misma máquina que ya ejecuta r7ex y eventosextremospub.

GitHub CLI

La recopilación usa la API de GitHub mediante gh, con la sesión iniciada.

# verificar
gh auth status

Claude Code + Codex

El guion y la revisión se hacen con claude -p; la portada, con Codex image_gen. Ambos mediante suscripción.

# verificar
claude --version && codex --version

Node + Python + ffmpeg

Renderizado en Chrome con Playwright, edición con ffmpeg y Whisper de inemavox para sincronizar las palabras.

# instalar el motor
cd ~/projetos/gitbombando && npm install

Estudio de HeyGen

Perfil con sesión iniciada en ~/.cache/inemaccbot/perfil-heygen, pantalla :99 (stack99). El avatar se crea en el estudio, nunca mediante la API.

# la pantalla :99 debe estar activa
systemctl --user status stack99

yt-pubx

Publica en el canal lives4 (INEMA Tec) con título, descripción y etiquetas.

~/projetos/yt-pubx/yt-pubx canais | grep lives4

Telegram

Sesión de telegramtopicosindex (cuenta de Nei) para publicar en el tema fijo de INEMA.TOOLS.

ls ~/projetos/telegramtopicosindex/telegram_session.session
Guía de uso · paso a paso

Activar, probar y hacer seguimiento

Una vez activado, no hay que hacer nada: el video sale a las 16 h. Estos pasos sirven para instalar, probar y solucionar problemas.

1

Activar los dos temporizadores

El registro de cada hora arma la curva de estrellas; el de las 16 h crea y publica el reel.

cp auto/systemd/gitbombando* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now gitbombando-retrato.timer gitbombando.timer  # verificar con: systemctl --user list-timers | grep gitbomb
2

Ver el Top 10 sin guardar nada

Solo recopila datos: guarda pesquisa/top10.json con las estrellas, la descripción, el README y el crecimiento de cada proyecto.

python3 coleta/trending.py edicoes/teste dia   # o semana / mes
3

Ejecutar una edición de prueba (sin publicar)

Hace todo, incluido el avatar, pero no publica en YouTube, el bot, Telegram ni git. El registro queda en rodada.log y la hoja de cuadros, en build/folha.jpg.

SEM_YT=1 SEM_BOT=1 SEM_TG=1 SEM_GIT=1 auto/rodar.sh 2026-10-28 dia
4

Publicar una edición lista

Si la revisión la rechaza, el video no se publica y el bot avisa. Si te parece que está bien, publícala manualmente en lives4, el bot v3 y el tema de INEMA.TOOLS.

python3 gb.py publicar edicoes/2026-10-28-top10-dia
5

Repetir solo una etapa

gb.py tiene un comando para cada etapa; cada uno lee el archivo ficha.yaml y el top10.json de la carpeta.

python3 gb.py checar  edicoes/<pasta>   # control del guion
python3 gb.py imagens edicoes/<pasta>   # portada, ranking, 10 tarjetas
python3 gb.py cena    edicoes/<pasta>   # tiempos + ritmo + cena.js
python3 gb.py render  edicoes/<pasta>   # video.mp4
python3 gb.py revisar edicoes/<pasta>   # hoja + revisión
6

Omitir un día

Una línea con la fecha omite todo el día; con la fecha y el modo, omite solo ese modo.

echo "2026-11-02" >> auto/pular.txt          # omite todo el día
echo "2026-11-02 semana" >> auto/pular.txt   # omite solo el de la semana
